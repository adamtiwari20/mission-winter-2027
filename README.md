# Mission: Winter 2027

An AI-assisted motivational lock screen and live countdown microsite designed for the Handshake x Google countdown-lock-screen mission.

## What is included
- `wallpaper.png` — static 1080 x 1920 mobile lock screen image.
- `cover.png` — 1500 x 1000 Handshake cover image (3:2 ratio).
- `index.html` — static webpage with editable real-time countdown, local date persistence, and download buttons.
- `artwork-original.png` — initial AI-generated image.

## Publish with GitHub Pages
1. Create a *new public* GitHub repository, e.g. `mission-winter-2027`.
2. Upload `index.html`, `wallpaper.png`, and `cover.png` at the top level of the repository.
3. Open Settings > Pages > Build and deployment > Deploy from a branch. Select `main` and `/ (root)`, then Save.
4. Open the Pages URL GitHub gives you: typically `https://YOUR-USERNAME.github.io/mission-winter-2027/`.
5. Confirm countdown loads, select a target date, and download the wallpaper.
6. For Handshake, submit the Pages URL with `cover.png` as the cover image.

## Important
This is not a native Android/iOS live lock-screen widget. Phone OS wallpapers remain static; the live countdown is on the companion webpage. The displayed date of January 6, 2027 is an editable project target, not an assertion of a university academic-calendar date.
